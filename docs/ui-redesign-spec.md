# LLMmodol · Local AI Studio — UI Redesign 设计规范

> 版本：v2.1 设计稿（待确认）  
> 方向：深色专业 IDE 风 · 复古机械运转感 · 单页应用 + 全屏画布  
> 原则：不套模板、不做光效；所有动效模拟真实机械运动，且必须承载状态信息。

---

## 1. 设计概念：「机械工作台」(Clockwork Bench)

本地 AI 工作台的本质隐喻：**一台正在运转的复古机械装置**。模型加载是"引擎点火"，推理是"飞轮转动"，工作流是"齿轮组啮合传动"，监控页是"仪表盘"。视觉语言围绕三个词展开：

- **深邃（Depth）**：近黑的墨蓝灰底色，层级靠材质厚度区分——背景越深越靠后，面板像一层层铆接的金属板，越亮越贴近用户。
- **机械（Clockwork）**：所有"活"的状态（加载中、推理中、运行中）用物理机械语言——旋转的齿轮、推进的活塞、跳动的指针、逐格咬合的进度齿——而非光效。
- **刻痕（Engraving）**：文字与分隔用蚀刻细线 + 等宽数字；数字像老式计数器的滚轮，标题像铭牌冲压字。

反模式（明确不做）：
- 不做渐变紫蓝 AI 风、**不做激光/流光/霓虹/辉光等一切"光效"**、不做圆角气泡聊天软件风。
- 动效时长全部 ≤ 300ms（机械循环动画除外），运动曲线偏"机械阻尼感"（起步快、停稳），禁止弹性果冻效果。
- 不用 emoji 做图标；图标用几何线条符号（◉ ◇ ◈ ↗ ⌁ 体系延续，重绘为统一线宽 SVG），关键机械元素（齿轮、指针）用 2px 线稿 SVG。

## 3. 字体与排版

### 3.1 字体族

```
--font-ui:   "Inter", "PingFang SC", "Microsoft YaHei UI", system-ui, sans-serif
--font-mono: "JetBrains Mono", "Cascadia Code", Consolas, monospace
--font-disp: "Space Grotesk", "Inter", "PingFang SC", sans-serif  /* 标题展示 */
```

全部本地打包（woff2 子集），**移除 Google Fonts 远程依赖**（当前 style.css 第 1 行 @import 与离线定位矛盾）。

### 3.2 字阶（1.25 比例）

| 层级 | 字号/行高 | 字重 | 用途 |
|---|---|---|---|
| display | 22/30 | 600 | 页面标题 |
| h2 | 16/24 | 600 | 卡片标题、面板标题 |
| h3 | 14/20 | 600 | 区块标题 |
| body | 13/20 | 400 | 正文、消息 |
| body-strong | 13/20 | 500 | 强调正文 |
| caption | 12/16 | 400 | 辅助说明 |
| micro | 11/14 | 500 | 徽章、标签、时间戳 |
| code | 12.5/20 | 400 | 代码、参数、ID（mono） |

数字（token 数、耗时、温度）一律 `--font-mono`，并开启 `font-variant-numeric: tabular-nums` 保证跳动数字不抖动。

### 3.3 间距系统

4px 基网：`--sp-1:4 --sp-2:8 --sp-3:12 --sp-4:16 --sp-5:24 --sp-6:32 --sp-8:48`。圆角：`--r-sm:6 --r-md:10 --r-lg:14`，画布节点 10px，卡片 12px，按钮 8px。

## 4. 动态语言：机械运动学（Motion Spec）

所有动效模拟**真实机械部件的物理运动**：旋转、啮合、活塞推进、指针摆动、滚轮计数。运动曲线统一用"机械阻尼"（`cubic-bezier(0.25, 0.9, 0.3, 1)`：起步果断、停稳不晃）。

### 4.1 核心机械原语（5 个，全局复用）

**① Gear（齿轮空转）** — 一切"正在运行/处理中"  
```
一个 2px 线稿小齿轮（黄铜色）匀速旋转，1.2s/圈，linear
用于：加载中按钮、运行中节点角标、侧边栏运行状态、KPI 卡加载
变体：双齿啮合（大轮带小轮反转）用于"多步处理"（Agent 工具循环）
```

**② Ratchet（棘轮推进）** — 进度与步骤  
```
进度条不是平滑填充，而是逐格"咬合"前进：每格 8px 宽，到位时有 1px 的回弹（像棘爪入槽），每格 120ms
用于：模型加载进度、文件上传进度、工作流步骤推进
```

**③ Needle（指针偏转）** — 实时指标  
```
仪表盘指针绕轴摆动到目标值，300ms 机械阻尼曲线；波动时指针轻微抖动（振幅 ±1°，仅 GPU 温度/显存这类实时值）
用于：监控页仪表、显存占用环、状态条指示
```

**④ Counter（滚轮计数）** — 数字变化  
```
等宽数字像机械计数器一样逐位垂直滚动到位，200ms；多位数字从右往左级联（个位先动）
用于：token 计数、运行次数、KPI 数值、耗时显示
```

**⑤ Stamp（冲压入场）** — 新内容出现  
```
opacity 0→1 + translateY(3px→0)，160ms，一步到位（像铭牌被压进钢板）
用于：消息出现、卡片入场、toast；不做 scale、不做光
```

### 4.2 特色机械细节（创意点，克制使用）

1. **发送·拉杆**：点击发送按钮的瞬间，按钮像机床拉杆一样下沉 2px 并短暂停留 80ms（按压行程感），同时输入框内容"被吸走"（向上收缩消失，150ms），随后 AI 消息槽位出现一个空转的齿轮占位符，第一个 token 到达时齿轮停止、内容 Stamp 入场。
2. **推理·飞轮**：流式输出期间，消息区右上角有一个小飞轮（16px 线稿）持续转动，转速与 token 速率挂钩（快则快转），输出停止时飞轮带惯性缓停（600ms 减速至静止）。—— 整个界面唯一常驻的"机器在转"信号。
3. **工作流·传动链**：运行经过节点时，该节点的入边像链条传动一样**逐节推进**（虚线段沿边方向步进，模拟链条滚子），节点顶部色条像活塞一样从左推到右（200ms），推满即完成态。并行分支是多条链条同时传动。
4. **审批·道闸**：运行进入 waiting_approval 时，流程线上落下一道道闸（黄黑斜纹横杆从上落下，250ms 机械阻尼），trace 面板同时弹出审批卡；批准后道闸抬起，传动链继续。
5. **点火序列**：模型加载 = 引擎点火——加载卡片上依次亮起三个阶段刻字（"接通 → 预热 → 点火"），每阶段一个棘轮格推进，完成时齿轮图标从静止启动加速到匀速（起步带 200ms 加速曲线，不是直接满速）。
6. **页面切换·滑台**：视图切换时主内容区像机床滑台一样横向平移 12px 入场（200ms 阻尼），侧边栏指示器是一个 3px 宽的黄铜滑块沿轨道滑动到位（250ms），到位瞬间有一个 1px 的轻微过冲回正（机械限位感）。

### 4.3 性能与约束

- 齿轮/飞轮用 SVG `transform: rotate()` 动画；棘轮/链条用 `transform` 步进；禁止 `box-shadow`/`filter` 动画。
- `prefers-reduced-motion` 时：齿轮静止为状态图标、棘轮变普通进度条、指针瞬时到位、其余全部退化静态。
- 画布超过 50 节点时链条传动降级为静态着色（保留颜色态）。

## 5. 应用框架与信息架构

### 5.1 单页应用结构（React + 客户端路由）

```
/                  → 对话空间（默认）
/workflow          → Agent 工作流（列表 + 编辑器全屏模式）
/workflow/:id      → 工作流编辑器（全屏画布）
/models            → 模型与 API
/runs              → 运行记录
/runs/:id          → 运行详情
/monitor           → 运行监控
```

技术：Vite + React 19 + TypeScript + react-router（或 wouter 轻量路由）+ Zustand（轻量 store，避免 Redux 模板感）。现有 workflow-ui 的 @xyflow/react 12 继续用，整个 workflow-ui 源码迁入主工程作为 `/workflow` 路由的编辑器模块，**不再维护两个工程**（web/studio-assets 独立页废弃）。

### 5.2 应用骨架

```

│  ▓ 侧边栏 56px（窄图标轨） ▓  主内容区                  │
│  ┌──────┐  ┌─────────────────────────────────────────┐ │
│  │ logo │  │  顶栏 40px：面包屑 + 全局状态 + 操作     │ │
│  │  ◉   │  ├─────────────────────────────────────────┤ │
│  │  ◇   │  │                                         │ │
│  │  ◈   │  │           视图内容（路由出口）           │ │
│  │  ↗   │  │                                         │ │
│  │  ⌁   │  │                                         │ │
│  │      │  │                                         │ │
│  │ ▔▔▔▔ │  ├─────────────────────────────────────────┤ │
│  │ 状态 │  │  状态条 28px：模型 · 显存 · 运行数 · API │ │
│  └──────┘  └─────────────────────────────────────────┘ │
└────────────────────────────────────────────────────────┘
```

关键变化（相对现状）：
- 侧边栏从 220px 文字导航改为 **56px 图标轨**（hover 展开 200px 浮层标签），主区面积 +18%。
- 新增**全局状态条**（底栏）：常驻显示已加载模型、显存占用条、活跃运行数（点击直达监控）、API 服务状态。当前这些信息散落在侧栏底部和监控页。
- 顶栏右侧放**模型快速切换器**（下拉即换，无需进模型页）。
- 快捷键：`Ctrl+K` 全局命令面板（跳转视图/切换模型/新建会话/运行工作流）；`1-5` 切视图（兑现现有 `<kbd>` 承诺）；`Ctrl+/` 快捷键 cheatsheet。

## 6. 页面线框（文字稿）

### 6.1 对话空间 `/`

```
┌─ 图标轨 ─┬──────────────────────────────────────────────┐
│          │ 对话 · [模型: Qwen3.5-0.8B ▾] [⚙ 参数] [+ 新会话] │
│          ├──────────┬───────────────────────────────────┤
│          │ 会话栏    │  ◇ 欢迎 · 今天想做点什么？         │
│          │ 240px    │  ┌─ 建议卡片 ×3 ──────────────┐  │
│          │ ▸ 今天    │  │ 解释这段代码 / 总结文件 / … │  │
│          │  ·会话A ●│  └─────────────────────────────┘  │
│          │  ·会话B  │                                   │
│          │ ▸ 更早    │  ── 有消息时 ──                   │
│          │          │  U ████ 用户消息（右对齐深色块）    │
│          │ [搜索]   │  A ████ AI 消息（Markdown渲染）     │
│          │          │      └ 代码块：语言标签+复制按钮    │
│          │          │      └ 右上飞轮转动（流式时）       │
│          │          ├───────────────────────────────────┤
│          │          │ [📎 文件chip]                      │
│          │          │ ┌─ 输入框（自动增高）──────────┐ ⏹ │  ← 流式时 ⏹ 停止
│          │          │ │ 输入消息，Enter 发送…        │ ↑ │  ← 发送（拉杆按压）
│          │          │ └─────────────────────────────┴───┘ │
│          │          │  temp 0.7 · max 768 · 已用 1.2k tok │
└──────────┴──────────┴───────────────────────────────────┘
```

交互与功能点：
- **Markdown 渲染**：GFM + 代码高亮（highlight.js 或 shiki 轻量子集，只打包常用 10 语言）+ LaTeX 可选；代码块带语言标签、行号（可选）、复制按钮、一键"插入到输入框"。
- **流式**：fetch stream + AbortController，⏹ 停止按钮随时中断；推理飞轮随 token 速率转动；断线自动保留已收内容并标记"输出中断"。
- **参数**：`⚙ 参数` 弹出小面板调 temperature / top_p / max_tokens / system prompt（会话级），替换硬编码 768/0.7。
- **会话栏**：可折叠；时间分组（今天/昨天/更早）；重命名（双击）、删除（hover 出现 ×）；搜索过滤。
- **建议卡片**：空态 3 张可配置卡片，hover 微浮起 + 黄铜边框变色。
- **文件**：chip 带类型图标与大小，上传进度内嵌 chip 内进度条；超出 15MB 前端即拦。
- **消息操作**：hover 出现 复制 / 重新生成 / 删除此轮 三个 ghost 按钮。

### 6.2 工作流编辑器 `/workflow/:id`（全屏模式）

进入编辑即隐藏图标轨与状态条（Esc 或左上角 ‹ 返回退出全屏），获得完整画布面积：

```
┌──────────────────────────────────────────────────────────┐
│ ‹ Agent工作流 │ [名: 文件研究员 ✎] v3 · 已发布v2 │ ✓已保存 │ │
│        [检查] [运行▶] [保存 Ctrl+S] [发布] [⋮]            │
├─── 步骤库 ──┬──────────────────────────────┬── 属性面板 ──┤
│ 悬浮浮层     │                              │  300px       │
│ (hover展开)  │        无限画布               │  节点配置     │
│ ▸ 智能       │   ┌────┐  flow  ┌────┐       │  ────────    │
│  Agent ◇     │   │节点│ ─────→ │节点│       │  连接目标     │
│  模型 ◉      │   └────┘        └────┘       │  ────────    │
│ ▸ 逻辑       │        ↘ 链条传动 ↗           │  结构检查 ✓  │
│  分支 ⑂      │                              │              │
│  循环 ↻      │   [minimap]   [缩放控件]      │              │
│ ▸ 数据       │   [整理布局] [网格吸附✓]      │              │
├─── 运行台 ──┴──────────────────────────────┴──────────────┤
│ ▶ 试运行 [输入…] [📎] │ trace 时间线（可过滤⚲） │ 审批卡   │
└──────────────────────────────────────────────────────────┘
```

编辑器增强点（在现有功能上新增）：
- **撤销/重做**：`Ctrl+Z / Ctrl+Shift+Z`，历史栈 50 步，顶栏显示"已保存/未保存·可撤销 n 步"。
- **复制粘贴**：`Ctrl+C/V/D` 节点与多选子图，跨工作流粘贴。
- **多选与对齐**：框选（拖拽空白）、`snapToGrid` 8px、对齐辅助线（拖动时显示品红参考线）、`Ctrl+Shift+L` 整理布局（dagre 自动分层）。
- **拖放补完**：步骤库节点可直接拖入画布落点创建（补上现有半成品）。
- **连线校验**：`isValidConnection` 即时禁止（自环、指向 start、重复连），condition 两出口同目标时连线橙色警告。
- **步骤库**：改为左侧窄条（40px），hover 展开分组浮层，不占常驻宽度。
- **快捷键**：`Ctrl+S` 保存、`Ctrl+Enter` 运行、`F` 适应画布、`Esc` 取消连线/关闭面板。
- **运行台**：trace 支持按节点/事件类型过滤 + 搜索；事件点击定位节点（已有，保留）；节点输出可直接在 trace 中复制 JSON。
- **深色画布**：React Flow 背景点阵 `--bg-abyss`，边默认 `--line-strong`，激活边链条步进传动，错误边 `--danger`。

## 8. 工程决策

1. **单工程**：新建 `web-react/`（或改造 `workflow-ui/` 为 `studio/`），Vite + React 19 + TS；`web/` 旧纯 JS 界面与 `workflow-ui/` 均在迁移完成后废弃。FastAPI 侧把 `/assets` 与 `/studio` 两个静态入口统一为新的 `/app-assets`，`/` 直接服务 SPA（含 history 路由 fallback）。
2. **依赖克制**：react-router（或 wouter）、zustand、@xyflow/react、marked（或 markdown-it）+ 高亮库、dagre（自动布局）。不引入 UI 组件库（保持独特视觉）、不引入 Tailwind（设计令牌用 CSS 变量即可，避免类名汤）。
3. **样式组织**：`tokens.css`（变量）+ `base.css`（reset/排版）+ 每视图一个 css 文件 + 组件级 css co-located；彻底废弃 style.css/refined.css 双主题覆盖体系。
4. **状态**：Zustand store 分 slice（runtime / conversations / workflows / runs / monitor）；SSE/轮询逻辑收进 store action，组件不直接 fetch。
5. **API 层**：单一 `client.ts`，自动生成错误 toast；流式封装 `streamChat()` 返回带 `abort()` 的句柄。
6. **构建**：产物输出到 `web/app-assets`，FastAPI 挂载；版本哈希由 Vite 处理，废弃 `?v=monitor-...` 手 bump。
